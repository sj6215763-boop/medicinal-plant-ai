# 🌿 Medicinal Plant AI

An AI-based web application that identifies medicinal plants from leaf images using a deep learning model.

## 📌 Project Description

Medicinal Plant AI is a plant identification application developed using Python, PyTorch, and Streamlit.

The user can upload an image of a plant leaf. The trained AI model analyzes the image and predicts the plant category along with its confidence score.

The application also provides:

* AI-based plant identification
* AI confidence score
* Fuzzy reliability score
* Top 3 prediction results
* Plant information
* Scientific name
* Traditional uses
* Precautions
* Prediction history
* Uploaded image storage

## ✨ Features

### 🌿 Plant Identification

Upload a JPG, JPEG, or PNG image of a plant leaf and receive an AI prediction.

### 🤖 Deep Learning Model

The application uses a trained MobileNetV3-Small image classification model.

### 📊 Prediction Confidence

The application displays the confidence percentage of the AI prediction.

### 🧠 Fuzzy Reliability

A fuzzy logic-based reliability score is calculated from the AI confidence.

### 🌱 Plant Information

The application displays plant information stored in an SQLite database.

### 📜 Prediction History

Previous predictions can be viewed along with prediction date and time.

## 🌿 Supported Plants

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sj6215763-boop/medicinal-plant-ai.git
```

Open the project folder:

```bash
cd medicinal-plant-ai
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Run:

```bash
streamlit run app.py
```

The application will open in the browser.

## 📷 How to Use

1. Open the Medicinal Plant AI application.
2. Click on the image upload option.
3. Select a plant leaf image.
4. Wait for the AI prediction.
5. View the predicted plant.
6. Check AI confidence and fuzzy reliability.
7. View plant information.
8. Check prediction history.
